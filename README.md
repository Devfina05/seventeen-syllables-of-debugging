One haiku about debugging, in the 5-7-5 shape, seventeen syllables in all. The program writes it to `/output/entry.txt`:

> a breakpoint at dawn
> the bug I chased all night long
> was one missing brace

The picture is concrete — a breakpoint, an all-night chase — and the last line turns the poem: the monster was a single missing brace.

## Run it

```sh
python3 main.py
```
